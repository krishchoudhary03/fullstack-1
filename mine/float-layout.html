CSS Float

1. Text wrap around a floated image

When an element is floated, it is taken out of normal flow and pushed to one side, letting inline content (like this paragraph) wrap around it. Without the clearfix on the parent, a container holding only floated children would collapse to zero height because floats don't contribute to the parent's height by default.
