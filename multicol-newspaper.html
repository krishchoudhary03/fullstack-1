Multi-Column Layout Makes a Comeback

Once reserved for print, the newspaper-style column layout is now trivial on the web thanks to the column-count and column-gap properties. A single block of text automatically flows from one column into the next, exactly like a printed page, without any extra markup or wrapper divs for each column.

column-rule draws a thin line between columns, and combining first-letter with float recreates the classic drop-cap look editors have used for centuries. column-span: all lets a heading break out and stretch across every column at once, which is useful for section titles inside a long article.

Together these properties turn a plain paragraph of text into something that instantly reads like a newspaper page, with zero JavaScript involved.
