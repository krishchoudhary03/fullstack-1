# CSS and HTML Practice

This repo has the HTML and CSS files I made while learning and practicing different concepts.

Most of the files are small exercises, so they can be opened directly in a browser without installing anything.


## What I practiced

Some of the topics in this repo include:

- Basic HTML and CSS
- Flexbox and CSS Grid
- Responsive navigation bars
- Cards and dashboard layouts
- Gradients and shadows
- Sticky positioning and scrolling
- Pseudo-classes
- CSS variables
- Tailwind CSS basics

## How to run

There are no dependencies needed. Just open any `.html` file in a browser.

You can also run the folder with:

```bash
npx serve .
```

This is a learning project, and I’ll keep adding more practice files as I learn new things.
